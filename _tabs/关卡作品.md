# SHADOW

使用UE制作的3d版类《小小梦魇》风格线性关卡。关卡展现了一个患有抑郁症的女孩的内心世界。玩家具有能和影子交互的能力，通过操控女孩在关卡中解谜探索，帮助女孩打开心扉，击败内心束缚自己的怪物。

# 黑潮

主角是一名年轻的盗窃犯。在一次盗窃中因一时贪念失手杀死了屋主（淹水致死）。此事如同利刺般扎入他心中，使他彻夜难眠。传闻位于孤岛的米歇尔山能够赐予心灵的救赎，他便抱着试试看的心态踏上山路，以求得内心的安宁。

然而登山途中，水鬼游荡、黑潮涌动，更不断出现与他一模一样的幻影，逼迫他直面自我。当他在山顶击败了最后的化身时，他才明白：整座米歇尔山就是他内心的映照。他在这段攀登中完成了真正的救赎。

# 时间回溯

在遥远的过去，大地上曾存在一支被誉为“时语者”的古老文明。他们不以武力称雄，也不以财富闻名，而是以对“时间”的感知与操控技艺立于诸文明之巅。他们留下的遗迹——“时域神庙”——隐藏在世界偏远角落，仅对极少数人开启。传说进入神庙的人将获得时间回溯的能力。 主角为一名考古学者，为了追寻“时语者文明”的真实历史只身进入时域神庙探险……
